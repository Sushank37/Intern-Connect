# Intern-Connect
A lightweight AI-based web app that recommends 3–5 personalized internships based on a candidate’s skills, education, interests, and location. Built for SIH, it features a simple, mobile-friendly UI and can be easily integrated with the PM Internship Scheme portal.
# 🌟 SIH Final – AI-Based Internship Recommendation Web App

## 🧠 Overview
This project is a lightweight **AI-powered internship recommendation system** developed for the **Smart India Hackathon (SIH)**.  
It suggests **3–5 personalized internship opportunities** to candidates based on their **skills, education, interests, and location preferences**.  

The system is designed to be **simple, mobile-friendly, and accessible** even for users with limited digital literacy. It can be seamlessly integrated with the **PM Internship Scheme portal**.

---

## 🚀 Features
- AI-based or rule-based recommendation engine  
- Captures candidate details (education, skills, sector interests, location)  
- Displays top 3–5 personalized internship suggestions  
- Minimal, intuitive, and mobile-responsive UI  
- Lightweight deployment (works well on low-resource systems)  
- Easy integration with government or institutional portals  

---

## 🧩 Tech Stack
- **Frontend:** HTML, CSS, JavaScript, TypeScript  
- **Backend:** Flask / Node.js / Django *(adjust based on your stack)*  
- **AI Logic:** Python (rule-based or ML-light model)  
- **Database:** SQLite / MySQL  
- **Hosting:** Render / Vercel / Local Server  

---

## 🖥️ How It Works
1. User enters profile details – education, skills, interests, and location.  
2. The system processes inputs using a rule-based or ML-light model.  
3. Displays top 3–5 relevant internships as simple, clear cards.  

---

## 📱 UI Highlights

- Mobile-compatible interface
